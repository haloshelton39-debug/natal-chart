📦 Структура проекта

Приложение состоит из следующих файлов:

  • natal_chart_app.html — Главное приложение (~64 KB)
  • vendor/astronomy-engine.min.js — Библиотека Astronomy Engine (~135 KB)
  • QUICK_START.txt — Быстрое руководство пользователя
  • readme.md — Полная документация с примерами
  • TECHNICAL.md — Техническая информация для разработчиков
  • astrology_data.json — Справочные данные в формате JSON
  • index.html — Этот файл (навигация по проекту)

❓ Часто задаваемые вопросы

Почему всё в одном файле?
Для удобства использования. Просто открой файл — и готово. Нет зависимостей, нет установки.

Требуется ли интернет?
Расчёты выполняются локально, но для поиска городов нужен интернет (используется OpenStreetMap API).

Безопасны ли мои данные?
Да, полностью. Все расчёты выполняются в браузере, данные не отправляются на сервер.

Как точны расчёты?
Приложение использует точные астрономические модели через Astronomy Engine. Для профессиональных целей можешь использовать ZET или Solar Fire, но для личного использования точности хватает.

На каких браузерах работает?
Chrome, Firefox, Safari, Edge и другие современные браузеры (требуется поддержка HTML5 и ES6).
